# Hands-On Labs

Each lab is designed to produce portfolio evidence without exposing credentials.

## Required Evidence Pattern

For each lab, capture:

1. Objective
2. Architecture / request flow
3. IAM JSON or configuration
4. Validation command or console evidence
5. Expected allowed action
6. Expected denied action
7. Security interpretation
8. Cleanup

A successful lab should demonstrate both **what is allowed** and **what is intentionally denied**.
