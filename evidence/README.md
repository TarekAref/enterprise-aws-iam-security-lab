# Evidence Guide

This directory is reserved for **sanitized proof of hands-on work**.

Recommended naming pattern:

```text
lab-01-policy-attached.png
lab-01-read-success.png
lab-01-delete-denied.png
```

For every image, add a companion Markdown note describing:

- What the evidence proves
- Which principal/role was used
- Which action was tested
- Expected result
- Actual result
- Security conclusion

Do not upload screenshots containing secret access keys, session tokens, MFA seeds, passwords, or unnecessary personal/account information.
